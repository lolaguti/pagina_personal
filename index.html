TRABAJO FIN DE GRADO · 2026

Optimización de horarios

¿Cómo se pueden organizar los horarios universitarios para reducir las coincidencias entre las asignaturas en las que está matriculado cada estudiante?

Este proyecto aborda el problema mediante modelización matemática y algoritmos heurísticos, con el objetivo de mejorar la planificación de horarios de los grados en Matemáticas, Física y Estadística, y del doble grado en Matemáticas y Estadística de la Universidad de Extremadura.

Proceso:

  • Modelización y optimización:

    Formulación del problema mediante programación entera y definición de las restricciones de planificación.

  • Experimentación con heurísticas:

    Implementación y comparación de algoritmos genéticos, enfriamiento simulado y búsqueda tabú en R. El análisis experimental identificó el enfriamiento simulado como el método más adecuado de los estudiados para este problema.

  • Base de datos y aplicación web:

    Diseño de una base de datos para gestionar estudiantes, profesorado y asignaturas, e integración de los resultados en una aplicación web que permite consultar horarios individualizados.

Resultados

En el ejemplo estudiado en la memoria, las coincidencias del horario de un estudiante de Matemáticas se redujeron de 5 a 2 tras la optimización.

Tecnologías utilizadas

  • R / RStudio
  • MySQL
  • PHP
  • HTML
  • CSS
  • JavaScript

BACHELOR'S THESIS · 2026

Timetable Optimization

How can university timetables be organized to reduce clashes between the courses in which each student is enrolled?

This project addresses the problem through mathematical modelling and heuristic algorithms, aiming to improve timetable planning for the Mathematics, Physics, and Statistics degree programs, as well as the double degree in Mathematics and Statistics at the Universidad de Extremadura.

Methodology:

  • Mathematical Modelling and Optimization:

    Formulation of the problem using integer programming and definition of scheduling constraints.

  • Heuristic Experimentation:

    Implementation and comparison of genetic algorithms, simulated annealing, and tabu search in R. The experimental analysis identified simulated annealing as the most suitable method among those evaluated for this problem.

  • Database and Web Application:

    Design of a database to manage students, faculty members, and courses, and integration of the results into a web application that allows users to view personalized timetables.

Results

In the example analyzed in the thesis, timetable clashes for a Mathematics student were reduced from 5 to 2 following optimization.
